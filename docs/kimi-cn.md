# 获取 Kimi 凭据

1. 打开 [Kimi 官网](https://kimi.moonshot.cn) 并登录。
2. 按照下方教程获取 `refresh_token` 和 `access_token`。
3. 在扩展服务配置中，将两个值分别填入名称对应的字段。
