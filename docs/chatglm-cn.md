# 获取智谱清言（ChatGLM）凭据

1. 打开[智谱清言官网](https://chatglm.cn)并登录。
2. 按照下方教程获取 `refresh_token` 和 `token`。
3. 在扩展服务配置中，将两个值分别填入名称对应的字段。
