# ChatGPT 常见问题

## 登录或请求时遇到错误怎么办？

![错误示例](https://github.com/nextai-translator/nextai-translator/assets/1206493/be75f564-21ba-4531-8875-7cd5e8bc554b)

可以尝试以下步骤：

1. 登录 [ChatGPT](https://chat.openai.com/)。
2. 新建一个对话并发送一条简单消息。
3. 等待页面正常返回。
4. 回到 NextAI Translator，重新尝试请求。

操作示例：

https://github.com/nextai-translator/nextai-translator/assets/1206493/e0d04d55-d1c3-452c-8b70-55dc2167540e

如果问题仍然存在，请检查网络连接、服务状态、账号权限和扩展配置。
